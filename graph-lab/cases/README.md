# Cases

Один case — маленькая проверяемая гипотеза, а не снимок всех 50 тысяч узлов. Добавляйте
реальный service pair или orchestrator и фиксируйте минимум известных входов/выходов/связей.
Не указывайте точное общее число CodeSymbol: оно ломает полезные улучшения.

`required_edges` доказывает recall, `forbidden_edges` защищает precision. Имена могут быть
service id, label или точным alias. `operation_contains` — осознанно частичное сравнение,
полезное для URL с переменными пути.
