# Experiments

Каждый increment алгоритма должен иметь один каталог:

- `PLAN.md` — какая измеримая проблема и какой case её воспроизводит;
- `HYPOTHESIS.md` — какой общий механизм теряет/создаёт связь;
- `CHANGESET.md` — какие правила/файлы изменены и почему;
- `VALIDATION.md` — команды, passed run ids, время и память;
- `COMPARISON.json` — delta относительно production версии;
- `CONCLUSION.md` — принять, переделать или отклонить.

Не смешивайте несколько причин в один increment. Если hypothesis неверна, запишите это как
результат: отрицательный эксперимент тоже предотвращает повторение бесполезной правки.
