        Общая память АС

        Опыт и уроки из запросов помогают всем пользователям с доступом к связанным источникам. Источники проверяются заново. Чаты и неподтверждённые ручные черновики остаются личными.

        Переключатель действует только на ваши новые запросы: использование общей памяти и автоматическое сохранение опыта. Общая память продолжает работать для остальных пользователей. Добавлять записи вручную можно при любом положении переключателя.

        Автоматический опыт — неподтверждённая подсказка. Оценки «Помогло» и «Не помогло» уточняют общий опыт АС. Счётчик учитывает использование записи всеми пользователями. Изменить или удалить запись может только её автор.

        Новая запись

        Связанные источники

        Общая запись доступна только пользователям с доступом ко всем связанным источникам и используется в соответствующей области поиска.

        В вашей области доступа пока нет записей. Общий опыт появится автоматически после завершения запросов с включённой памятью. Можно добавить проверенную заметку.

        Вход в Harness

        Если вы уже вошли в портал, дополнительный вход обычно не нужен. Здесь можно указать ключ доступа к порталу или пароль администратора. Ключ от модели не требуется.

        Настройки модели и сертификатов доступны администратору. При отдельном запуске Harness выберите «Ключ доступа» и укажите ключ администратора (HARNESS_ADMIN_TOKEN). Обычный ключ пользователя не даёт прав на изменение настроек.

        Сохранится только в этой вкладке. Не передаётся в адресной строке.
