# Agent Harness

Самостоятельный модуль вопросов и исследований: собственная страница, HTTP API,
очереди быстрых запросов и исследований, усилие, отмена и личная история SQLite.
Пакет не импортирует портал, его RAG, GigaCode, LangChain или интерфейс dashboard.

Установите проект из каталога с `pyproject.toml`: `pip install .`.
Задайте секрет `HARNESS_API_TOKEN` длиной не менее 32 символов и запустите
`python -m agent_harness`. По умолчанию страница доступна на
`http://127.0.0.1:8020/`. В форме входа выберите токен. Секрет не передаётся в URL.
Адрес и порт задаются `HARNESS_HOST` и `HARNESS_PORT`.

Без провайдеров интерфейс сообщает, что источники и модель не подключены.
Для реальной работы задайте `HARNESS_PROVIDER_FACTORY=my_package.providers:create`.
Функция без аргументов возвращает `(source, model)` по интерфейсам `contracts.py`.
Провайдеры — доверенный серверный код. Они проверяют права на каждом чтении,
ограничивают результаты и реагируют на `cancel`. Модель должна возвращать проверенный
JSON `content` / `tool_calls`; собственных внешних действий она не выполняет.

Токен стандартного standalone-входа представляет одну общую учётную запись. Для
личной истории нескольких пользователей передайте в `http.create_app` собственную
функцию `authenticate(request) -> Principal | None` со стабильным серверным owner_id.
Не доверяйте `owner_id`, присланному браузером. Источники должны повторно проверять
права при выполнении фоновой работы.

Хранилище задаётся `HARNESS_STATE_DIR`; используйте отдельный каталог на процесс.
Один процесс обслуживает две независимые очереди. Это локальный пилот: несколько
ASGI workers над одной SQLite-очередью не поддерживаются. Незавершённые работы после
перезапуска помечаются прерванными. Результаты и история сохраняются; автоматическое
обучение модели и общая проверенная память не реализованы.

Статические файлы лежат в `static/` и не требуют Node, сборки или CDN.
Сервис можно монтировать в другой Starlette/ASGI app под собственным префиксом.
Родительское приложение должно запускать lifespan модуля и останавливать его вместе
со своими задачами. Не подключайте модуль, когда его feature flag выключен.
