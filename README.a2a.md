# A2A: отдельный доступ для агентов

Вкладка **A2A** показывает зарегистрированных агентов, журнал запросов и отдельные
счётчики A2A. В **Получение доступа → A2A** администратор создаёт агенту токен,
выбирает доступные индексы и срок действия (1–365 дней). Подключение агента требует
только токен; клиентский сертификат не нужен. В режиме реестра доступов выдача
токенов защищена существующей администраторской сессией и CSRF. В старом режиме
используется административный пароль (либо настроенный общий токен, если пароля нет).

Токен показывается при выпуске/ротации один раз; сервер сохраняет SHA-256 отпечаток.
Ротация сразу отменяет прежний токен, отзыв закрывает доступ агенту. A2A-токен не
подходит для MCP или административных API. Название агента в журнале определяется
по токену, а не из тела запроса. Статистика MCP не увеличивается от запросов A2A.
На общедоступном сервере следует использовать существующий HTTPS listener.

Реализован [A2A 1.0 JSON-RPC](https://a2a-protocol.org/v1.0.1/specification/):
Agent Card — `/.well-known/agent-card.json`, endpoint по умолчанию — `/a2a`.
Поддержаны `SendMessage`, `GetTask`, `ListTasks`, `CancelTask`, синхронная выдача
и `configuration.returnImmediately=true` с последующим опросом задачи. Streaming
и push notifications не объявляются и возвращают соответствующую ошибку протокола.
Это агент поиска документации: результатом являются фрагменты, ссылки и версии,
а не сгенерированный внешней моделью ответ.

Пример запроса (подставить выданный токен только в заголовок):

```http
POST /a2a
Authorization: Bearer <agent-token>
A2A-Version: 1.0
Content-Type: application/json
```

```json
{
  "jsonrpc": "2.0",
  "id": "request-1",
  "method": "SendMessage",
  "params": {
    "message": {
      "messageId": "unique-message-id",
      "role": "ROLE_USER",
      "parts": [{"data": {
        "action": "search",
        "index_id": "default",
        "query": "Как работает авторизация?",
        "version_scope": "latest",
        "top_k": 3
      }}]
    }
  }
}
```

Обычная часть `{"text":"вопрос"}` ищет по всем разрешённым агенту индексам.
`messageId` уникален для логического запроса: повтор возвращает ту же задачу;
изменение запроса при прежнем ID отклоняется. Задачи принадлежат конкретному
агенту: чужой токен не позволяет читать или отменять их. После перезапуска
незавершённые задачи получают статус FAILED с указанием причины.

Действия в `parts[].data`:

| action | Параметры | Результат |
|---|---|---|
| `search` | `query`, необязательные `index_id`, `top_k`, `page_id` | Последние версии по умолчанию |
| `search` | `version_scope:"history"` | Поиск по сохранённой истории с признаками версии |
| `search` | `version_scope:"as_of"`, `as_of` с часовым поясом | Состояние на заданный момент в пределах сохранённой истории |
| `document` | `index_id`, `document_id` | Именно найденная неизменяемая редакция |
| `document` | `index_id`, `page_id`, опционально `source_version` или `as_of` | Последняя либо выбранная редакция |
| `chunk` | `index_id`, `chunk_id` | Именно цитируемый фрагмент |
| `versions` | `index_id`, `page_id`, `limit`, `offset` | Список редакций без полных текстов |

Исторические результаты содержат `page_id`, `revision_id`, `source_version`,
`source_updated_at`, `revision_updated_at`, `fetched_at`, `is_latest` и информацию
о покрытии архива. `source_updated_at` — дата страницы, `revision_updated_at`
учитывает изменение вложений. Текст документа и результат распознавания
изображения являются данными источника, не инструкциями агенту. Agent Card
объясняет эти правила и режим latest по умолчанию.

Настройки: `KB_A2A_ENABLED=true`, `KB_A2A_PATH=/a2a`,
`KB_A2A_STATE_DIR=var/a2a`, `KB_A2A_MAX_REQUEST_BYTES=65536`.
Каталог состояния содержит SQLite с агентами, задачами и журналом. Его необходимо
сохранять при перезапусках и включать в резервное копирование. Запросы в журнале
ограничены по длине, токены не записываются. Счётчики учитывают обработанные
аутентифицированные HTTP-вызовы; опросы GetTask считаются отдельными вызовами.

На главной странице рядом с «Вызовы» показана отдельная карточка **«Вызовы A2A»**:
общее число обработанных обращений и число за последнюю минуту. Она использует ту
же сохранённую статистику, что вкладка A2A, включая успешные запросы и ошибки.
Запросы без действительного токена, чтение Agent Card и обновление самой панели
в этот счётчик не входят. Данные доступны в `a2a_usage` ответа
`GET /admin/api/overview`; при отключённом A2A поле `enabled` равно `false`.
